# Oqulyq Lens

Платформа для методистов по кейсу «Data-Driven Curriculum» (EdTech Hackathon by Zhambyl Hub, 2026).

Анализирует результаты тестирования по темам учебной программы, выявляет сложные темы, сравнивает эффективность учебников и формирует обоснованные рекомендации по распределению учебных часов.

**Живое демо (MVP):** https://reimon173.github.io/oqulyq-lens/
**Презентация:** https://reimon173.github.io/oqulyq-lens/presentation/oqulyq-lens-pitch.html

## Возможности

- Выбор класса (7-11), предмета (алгебра, геометрия, физика, химия, биология, информатика) и региона (20 регионов Казахстана)
- **Темы:** усвоение каждой темы, разброс между школами, связь с числом часов
- **Учебники:** сравнение внутри каждой темы, t-тест Уэлча, вывод «значимо / не доказано»
- **Часы:** перераспределение внутри годовой нагрузки с прогнозом и обоснованием по каждой теме
- **Регионы:** сравнение со средним по стране и слабая тема каждого региона
- **ИИ-помощник:** отвечает только на вопросы о данных платформы. Встроенный аналитик работает везде; локальная нейросеть Qwen 2.5 (WebLLM) включается в Chrome или Edge с WebGPU
- Загрузка своих данных в CSV, интерфейс на трёх языках: қазақша, русский, English
- Пользовательское соглашение и политика конфиденциальности

## Стек

- HTML5, CSS3, Vanilla JavaScript, без фреймворков и сборки
- Графики: SVG, рисуются в коде
- Статистика реализована вручную: взвешенное среднее, линейная регрессия, t-тест Уэлча
- Локальный ИИ: WebLLM + Qwen2.5-1.5B-Instruct (по желанию пользователя)

## Запуск

Откройте `index.html` в браузере. Установка и сервер не нужны.

## Данные

Встроены модельные данные по стране (не официальная статистика): 6 предметов, 7-11 классы, 20 регионов, 100 школ.
Свои данные загружаются в разделе «Данные» файлом CSV:

```
school,region,textbook,topic,hours,students,score
School 14,Zhambyl,Textbook A,Electrochemistry,19,96,52.4
```

Файл обрабатывается в браузере и никуда не отправляется.
